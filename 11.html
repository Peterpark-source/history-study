① 통일 과정에서 나타난 신라 왕권 강화
문제 / 키워드정답O / X
태종 무열왕이 왕위에 오른 배경과 의의는? ★
당과 동맹을 체결했던 김춘추가 왕위에 오름 / 집사부 기능 강화 → 진골 귀족 견제
문무왕의 업적은?
당과의 전쟁에서 승리 → 삼국 통일 달성 / 당에 협력한 귀족 제거 → 왕권 강화 / 수중릉 형태로 만든 문무대왕릉에 묻힘
신문왕의 업적 3가지는? ★
① 김흠돌의 난 진압 → 강력한 왕권 확립 ② 국학 설치 → 인재 양성 ③ 관리에게 관료전 지급·녹읍 폐지 → 귀족 특권 제한
녹읍과 관료전의 차이는? ★
녹읍: 진골 귀족의 경제적 기반 → 세금 거두고 농민의 노동력도 이용 가능 / 관료전: 관리 보상으로 준 토지 → 세금만 거둘 수 있고 노동력 이용 불가
② 통일된 나라를 운영하기 위한 노력
문제 / 키워드정답O / X
행정 제도 정비의 배경과 전개는?
배경: 삼국의 백성을 하나로 통합·넓어진 영토 효과적으로 통치 / 전개: 백제·고구려 출신 관리에게 관등 수여, 옛 백제·고구려 땅에 신라의 행정 구역 설치 → 신문왕 때 주로 정비
9주 5소경이란? ★
9주: 전국을 9개의 주로 편성 → 옛 고구려·백제·신라 땅에 3개씩 / 5소경: 수도가 동남쪽에 치우친 문제 보완 → 전국 5개 주요 도시에 설치
5소경에 누구를 살게 했나? ★
신라 중앙 귀족 + 새로 들어온 가야·백제·고구려의 귀족들을 소경에 살게 함 / 총 6개 중심지(금성과 5소경)를 옛 고구려·백제·신라 땅에 2개씩 설치
중앙군과 지방군의 구성은?
중앙군: 신라 외에 백제·고구려·말갈 사람으로 구성된 군대 조직 / 지방군: 옛 삼국 지역에 고르게 배치해 삼국 통합 추구
시험 함정 — 직전 체크

X — 반대. 녹읍을 폐지하고 관료전을 지급해 귀족 특권 제한

O — 맞음
녹읍은 세금만 거둘 수 있고 농민의 노동력은 이용할 수 없었다?
X — 그건 관료전. 녹읍은 세금도 거두고 농민의 노동력도 이용 가능
5소경을 설치한 이유는 수도가 한반도 서북쪽에 치우쳐 있었기 때문이다?
X — 수도(경주)가 동남쪽에 치우쳐 있어 이를 보완하기 위해 설치
신문왕이 국학을 설치한 목적은 귀족의 특권을 강화하기 위해서다?
X — 인재 양성이 목적. 오히려 귀족 특권은 녹읍 폐지·관료전 지급으로 제한
