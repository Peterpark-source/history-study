주제 8 — 수와 당의 침략을 물리친 고구려

0개 맞음 0개 틀림 0개 미채점
① 수의 침략을 막아 낸 고구려
문제 / 키워드정답O / X
수가 중국 통일 후 각국의 반응은?
수: 고구려에 항복 요구·침략 / 고구려: 북쪽 돌궐·남쪽 왜와 손잡으려 함 / 백제: 수와 친선 / 신라: 수와 외교해 고구려 견제
고구려의 선제공격이란?
수의 항복 요구 거부 → 고구려가 요서 지역 등을 먼저 공격
살수 대첩(612)이란? ★
수 양제가 요동성 함락 못하자 별동대로 평양성 직공 → 을지문덕이 살수(청천강)로 유인해 수의 별동대 대파 → 고구려 이후 수의 공격 모두 방어
② 당의 침략을 물리친 고구려
문제 / 키워드정답O / X
연개소문이 정변을 일으킨 배경과 결과는? ★
연개소문이 정변으로 권력 획득 → 당이 고구려를 여러 차례 침략
안시성 전투(645)란? ★
당 태종이 요동성 등 여러 성 함락·안시성 공격 → 연개소문이 지원군 보냈지만 패배 → 안시성 고구려군·백성이 고립됐지만 당군에 맞서 승리
당의 전쟁 결과는?
당은 전쟁에서 패배했지만 소규모 군대를 보내는 전략으로 고구려를 괴롭힘
시험 함정 — 직전 체크
함정 포인트정답O / X
수는 고구려가 항복 요구를 거절하자 요서 지역 등을 먼저 공격했다?
X — 먼저 공격한 건 고구려 (선제공격)
고구려에서 연개소문이 정변을 일으켜 권력을 잡자, 당은 고구려를 여러 차례 침략했다?
O — 맞음
살수 대첩에서 을지문덕은 수의 별동대를 평양성에서 맞서 격파했다?
X — 살수(청천강)로 유인해 대파 (평양성이 아님)
안시성 전투에서 연개소문의 지원군이 승리해 당군을 물리쳤다?
X — 지원군은 패배. 안시성의 고구려군과 백성들이 자체적으로 당군에 맞서 승리
