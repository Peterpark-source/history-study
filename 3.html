주제 3 — 삼국과 가야의 성장

0개 맞음 0개 틀림 0개 미채점
① 삼국과 가야의 성립
문제 / 키워드정답O / X
고구려가 성립 과정에서 왕권이 강해진 배경은?
평야 지대로 영토 확장하는 과정에서 왕권 강화
고구려에서 왕위를 세습한 부는? ★
5부 중 계루부 고씨
백제의 성립 과정은?
마한의 소국 중 하나 → 고구려에서 내려온 세력 + 한강 유역 토착 세력 연합
백제가 초기에 마련한 체제는?
3세기에 마한 일부 정복 / 관리 등급 구분 / 율령의 기초적인 틀 마련
신라의 성립 과정은?
진한의 소국 사로국 → 고조선 멸망 이후 내려온 세력 + 경주 토착 세력 결합
신라 초기 세 성씨가 교대로 왕이 된 성씨는? ★
박씨 · 석씨 · 김씨
신라의 중앙 집권 체제 마련이 늦은 이유는?
중국 문물 받아들이기 어려운 한반도 동남쪽에 위치
가야 연맹의 특징은?
변한 지역 여러 나라가 연맹 / 금관가야가 초기 연맹 주도 / 풍부한 철·우수한 제철 기술 / 덩이쇠 낙랑·마한·왜에 수출
② 영토를 넓힌 백제와 각국의 체제 정비
문제 / 키워드정답O / X
백제 근초고왕의 업적은? ★
4세기 중반 북쪽(고구려 공격) + 남쪽(마한 세력 병합) 영토 확장 / 해상 교역망 장악(중국·가야·왜) / 칠지도(왜와 교류)
백제가 불교를 수용한 곳은?
중국 남조로부터 수용
고구려 소수림왕의 업적 3가지는? ★
불교 수용 / 태학 설치(유교적 소양 인재 양성) / 율령 반포
고구려가 위기를 맞은 이유는?
유목 민족이 세운 전연의 침략으로 수도 함락 + 백제의 공격으로 왕이 사망
신라 내물왕의 업적은? ★
4세기부터 김씨 왕위 세습 / 대군장을 뜻하는 마립간으로 왕호 변경 → 왕권 강화
신라 화백 회의란?
중요한 일은 귀족들의 합의로 결정하는 회의 제도
4세기 가야가 약화된 이유는?
해상 교역 위축(낙랑군 소멸·백제가 해상 교역망 장악) / 금관가야 중심의 연맹 결속력 약해짐
③ 중앙 집권 국가로 향하는 길
문제 / 키워드정답O / X
중앙 집권 국가의 왕위 계승 변화는?
연맹체(군장들이 왕 선출) → 왕권 강화 → 한 가문에서 왕이 나옴 → 부자 상속으로 발전
고구려 계루부 고씨, 신라 김씨의 공통점은?
왕권이 강해지면서 한 가문에서만 왕이 나오게 된 사례
율령이란? ★
율(律) = 각종 범죄에 대한 처벌 규정 / 령(令) = 제도와 행정에 대한 규정
관등제란?
관리나 벼슬의 등급을 나타내는 제도 → 군장 세력을 중앙 귀족으로 흡수
지방관 파견의 목적은?
중요한 지역에 지방관 파견 → 왕의 지배력 강화
삼국이 불교를 수용한 시기는? ★
고구려·백제 = 4세기 / 신라 = 6세기 (공인)
왕이 불교를 수용한 목적은?
왕 자신을 부처와 동일시하여 권위를 높임
시험 함정 — 직전 체크
함정 포인트정답O / X
백제는 근초고왕 때 해상 교역망을 장악해 중국·가야·왜와 교류했다?
O — 맞음. 칠지도는 백제와 왜의 교류 증거
왕권이 강해지면서 군장들이 모여 고구려의 계루부 고씨와 신라 김씨에서 왕을 뽑게 됐다?
X — 왕권이 강해지면서 오히려 군장들의 선출 없이 한 가문(고씨·김씨)에서만 왕이 나오게 됨
신라는 4세기에 불교를 공인했다?
X — 신라는 6세기 공인 (고구려·백제는 4세기)
소수림왕은 고구려의 영토 확장을 이끈 정복 군주다?
X — 소수림왕은 내부 체제 정비(불교·태학·율령). 영토 확장은 광개토 대왕
율령에서 율(律)은 행정, 령(令)은 처벌 규정이다?
X — 반대. 율 = 처벌 규정 / 령 = 제도·행정 규정
가야는 금관가야를 중심으로 끝까지 강한 연맹을 유지했다?
X — 4세기 이후 해상 교역 위축으로 금관가야 중심의 연맹 결속력이 약해짐
