주제 1 — 청동기 문화와 고조선의 등장

0개 맞음 0개 틀림 0개 미채점
① 청동기의 보급과 농사의 확대
문제 / 키워드정답O / X
청동기 문화가 보급된 시기는?
기원전 15세기경, 만주와 한반도
청동은 누가 주로 사용했나?
지배 계급 — 무기·장신구·제사용으로 사용 (농기구·생활도구는 돌·나무)
청동기 시대 농사 관련 유물 2가지는?
반달 돌칼(곡식 수확) · 토기(곡식 저장·조리)
청동기 시대 마을의 특징은?
강가·구릉에 위치 / 울타리·도랑으로 방어 / 제단 설치
② 청동기 시대 사회 변화
문제 / 키워드정답O / X
생산력 증가가 가져온 변화는?
인구 증가 → 마을 규모 확대 → 사유 재산 발생 → 다툼 증가
군장이란?
여러 집단을 통합한 정치 세력 → 정치·경제 권력 + 하늘 제사 종교 의식 담당
고인돌이란?
군장이 죽으면 많은 사람이 동원되어 만든 거대한 무덤
청동검·청동 장신구의 역할은?
자신의 권위를 드러내기 위해 착용
③ 고조선의 건국
문제 / 키워드정답O / X
고조선 건국에 유리한 지리적 조건 2가지는?
남만주·한반도 서북부 = 넓은 들판(농사 유리) / 중국·몽골 초원 인접(문물 수용)
고조선이 우리 역사상 최초의 국가인 이유는?
청동기 문화 바탕 → 더 큰 세력이 주변 정복·통합 → 국가 형태 갖춤
고조선의 성장 중심지는?
요동 지역과 대동강 유역 (비파형 동검·탁자식 고인돌 분포로 추측)
단군왕검의 의미는? ★
단군 = 제사장 / 왕검 = 정치 지배자 → 한 사람이 종교·정치 주관 = 제정일치 사회
기원전 5~4세기 고조선에 철기 문화가 더 발달한 이유는?
중국이 분열한 시기에 많은 사람이 이주해 옴
④ 고조선의 발전과 멸망
문제 / 키워드정답O / X
위만이 고조선 왕이 된 해는? ★
기원전 194년 (중국 한에서 망명 → 세력 키워 왕위 차지)
고조선이 한과 분쟁이 일어난 이유는?
한과 한반도 중남부 사이에서 중계 무역 → 한이 견제
고조선 멸망 배경은?
흉노와 갈등을 겪던 한이 고조선을 견제 → 전쟁
고조선 멸망 과정은? ★
한의 공격 → 1년 넘게 맞서 싸움 → 지배층 분열 → 왕검성 함락 → 멸망(기원전 108년)
고조선 멸망 이후 한이 설치한 것은?
고조선 옛 땅에 4개의 군 설치 (낙랑군 등) → 직접 지배
고조선 멸망이 주변 지역에 미친 영향은?
유민이 한반도 남부로 이동 → 그 지역 정치 집단 성장에 영향
시험 함정 — 직전 체크
함정 포인트정답O / X
청동기는 농민도 농기구로 사용했다?
X — 지배 계급만 사용. 농기구는 돌·나무
단군왕검에서 단군은 정치 지배자를 의미한다?
X — 단군 = 제사장 / 왕검 = 정치 지배자
고조선은 흉노와 관계를 맺어 한을 견제했다?
X — 흉노와 관계를 맺은 건 한. 고조선은 중계 무역으로 성장하다 한에 견제당함
고조선은 한의 공격에 바로 무너졌다?
X — 1년 넘게 맞서 싸웠고, 지배층 분열로 결국 멸망
고조선 멸망 후 한이 설치한 군은 몇 개?
4개 (낙랑군 포함) — 나머지 3개는 고조선 유민의 저항으로 일찍 없어짐
