주제 7 — 삼국의 종교와 학문

0개 맞음 0개 틀림 0개 미채점
① 불교의 전래와 거대 사찰의 건설
문제 / 키워드정답O / X
삼국 왕들이 불교를 수용한 이유는?
'왕은 곧 부처'라는 사상으로 왕권 뒷받침
경주 황룡사 구층 목탑의 의미는? ★
황룡사: 진흥왕 때 건축한 신라 최대 사찰 / 선덕 여왕이 이웃 나라 침략 막길 기원하며 건설 / 고려 시대 몽골군 침략으로 소실
익산 미륵사지의 의미는? ★
미래에 미륵불이 나타나 구원할 것이라는 미륵 신앙 기반 / 익산: 호남평야 중심·교통 요지, 백제 무왕이 사비 다음 가는 제2의 수도로 만들려 함
서산 용현리 마애여래삼존상이란?
백제의 대표적인 불상 / 마애불(바위나 절벽에 새긴 불상) / 여래 = '진리에 도달한 사람'
불교가 삼국의 토착 신앙에 미친 영향은?
토착 신앙을 소멸시키지 않고 융합 → 삼국의 주요 문화로 자리 잡음
② 신선 세계를 추구한 도교 문화
문제 / 키워드정답O / X
도교의 특징은?
자연 숭배 + 불로장생 추구 신선 사상 + 도가 결합 / 귀족 사회 중심으로 유행
고구려 사신도란? ★
도교 방위신인 청룡·백호·주작·현무 표현 (ex. 강서대묘 사신도 중 '현무도')
백제 금동 대향로란?
도교의 신선 세계가 표현된 향로 / 불교적 요소와 도교적 요소가 결합되어 표현됨
③ 다양한 학문의 발전
문제 / 키워드정답O / X
삼국의 유학 교육 기관·방식은? ★
고구려: 수도에 태학(유학 교육) / 백제: 오경박사(유학의 5가지 경전)를 두어 교육 / 신라: 화랑들이 유학 공부
천문학을 중시한 이유는?
왕을 하늘과 연결해 권위를 높임 / 계절 변화에 따른 농사 시기 파악
삼국의 천문학·역법 관련 유물·기관은? ★
고구려: 고분 벽화에 다양한 별자리 그림 / 백제: 역박사를 두어 역법 교육 / 신라: 천체의 움직임 관찰하기 위해 첨성대 제작
시험 함정 — 직전 체크
함정 포인트정답O / X
불교는 토착 신앙을 소멸시키고 삼국의 주요 문화로 자리잡았다?
X — 소멸이 아니라 융합 → 토착 신앙과 융합하며 자리 잡음
고구려에서는 수도에 태학이라는 교육 기관을 세워 유학을 가르쳤다?
O — 맞음
첨성대는 백제가 천체의 움직임을 관찰하기 위해 만든 것이다?
X — 첨성대는 신라 (백제는 역박사를 두어 역법 교육)
백제 금동 대향로는 불교적 요소만 표현됐다?
X — 불교적 요소 + 도교적 요소가 결합되어 표현됨
