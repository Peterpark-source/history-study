주제 9 — 신라의 삼국 통일

0개 맞음 0개 틀림 0개 미채점
① 백제의 멸망과 부흥 운동
문제 / 키워드정답O / X
나당 동맹 결성 배경과 내용은? ★
백제 의자왕이 신라 공격 → 신라가 당에 지원 요청(김춘추) → 당은 고구려 정복 위해 수락 → 나당 동맹 / 내용: 백제·고구려 멸망 후 대동강을 경계로 땅 나누기로 약속
백제 멸망(660) 과정은? ★
나당 연합군 공격 → 당군: 기벌포 상륙 / 신라 김유신군: 계백의 결사대를 황산벌에서 격파 → 수도 사비 함락 → 의자왕 웅진으로 이동해 항전 → 귀족 내분으로 항복
백제 부흥 운동의 전개와 결과는?
복신·도침·흑치상지 등이 각지에서 부흥 운동 / 왜에 지원군 요청(백강 전투, 663) → 지도층 분열·백강 전투 패배로 실패 → 백제 유민 일부 왜·고구려로 망명
② 고구려의 멸망과 부흥 운동
문제 / 키워드정답O / X
고구려 멸망(668) 배경과 과정은? ★
백제 멸망 → 당이 한반도에 군사 기지 설치·신라 군량 지원 / 연개소문 사망 → 지배층 권력 다툼 → 나당 연합군이 수도 평양성 함락
고구려 부흥 운동의 전개와 결과는?
검모잠·안승·고연무 등이 운동 / 당이 평양 중심으로 고구려 지역 지배 시도 → 고구려 유민이 요동·한성에서 저항, 신라가 지원 → 당의 강력한 공세·지도층 분열로 실패
③ 나당 전쟁과 신라의 삼국 통일
문제 / 키워드정답O / X
나당 전쟁 배경은?
당이 대동강 경계 약속 지키지 않고 한반도에 군사·행정 기구 설치
나당 전쟁 전개 과정은? ★
신라가 고구려 부흥 운동 지원 / 당이 차지한 백제 지역 점령 → 당·토번 전쟁 발발 → 당이 대규모 군대 서역 파견 → 신라가 매소성·기벌포에서 당의 육군·수군 격파
삼국 통일(676)의 의미와 한계는? ★
의미: 당을 물리치고 옛 고구려 땅 일부+옛 백제 땅 차지해 삼국 통일 / 한계: 신라와 함께 200년 이상 존재한 발해를 포함하지 않음
시험 함정 — 직전 체크
함정 포인트정답O / X
신라와 당은 백제와 고구려를 멸망시킨 뒤 대동강을 경계로 땅을 나눠 갖기로 약속했다?
O — 맞음 (하지만 당이 약속을 지키지 않아 나당 전쟁 발생)
신라는 매소성과 기벌포 전투에서 승리해 당의 군대를 몰아내는 데 성공했다?
O — 맞음 (매소성=육군, 기벌포=수군 격파)
백제 부흥 운동은 왜의 지원군을 받아 결국 성공했다?
X — 백강 전투(663)에서 패배, 지도층 분열로 실패
신라의 삼국 통일은 발해도 포함한 완전한 통일이었다?
X — 발해를 포함하지 않아 한계로 지적됨
